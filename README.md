# GitHub での開発

Node.js 22 以降を使用します。初回の取得と検証は次の手順です。

```sh
git clone https://github.com/sakuya-emi/pamphletstudio.git
cd pamphletstudio
npm ci
node -e "require('node:fs').mkdirSync('tmp', { recursive: true })"
npm test
npm run build
npm run dev
```

`tmp` は PDF テストの一時出力先です。`node_modules`、`dist`、`output`、`tmp`、`.env`、制作データの `.pamph` / `.pamplib` は Git 管理の対象外です。制作データは別途バックアップしてください。Mac のブラウザに保存したデータは GitHub には移行されません。

# 稲友祭 Pamphlet Studio

学園祭の企画・ポスター・協賛広告を登録し、A5縦のパンフレットを自動組版するローカルWebアプリです。開発ステップ1〜3の主要部分と、デザイナーモードの初期実装を含みます。Phase 1の全要件が完成したものではありません。

## 起動

Node.js 22以降を用意し、このフォルダで実行します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5173 を開きます。依存関係のインストール後はインターネットも外部アカウントも不要です。フォント・PDFワーカーはローカルに同梱しています。起動中のローカルサーバーは必要です。

配布ZIPには `node_modules` を同梱していないため、初回は `npm install` が必要です。その後はmacOSで `start.command`、Windowsで `start.bat` を実行しても起動できます。両OSの配布用ネイティブアプリ／インストーラーはまだありません。今回の追加実装と検証状況は `今回の実装・引き継ぎ.md` を参照してください。

```sh
npm test        # 自動組版・保存・PDF出力
npm run build   # 型チェックと配布用ビルド
npm run preview # ビルドしたWeb版を確認
```

## 最初の一冊を作る

1. ホームで「新規プロジェクト」、または「サンプルで編集をはじめる」を選択。
2. 左の「表紙」を選び、開催回数・テーマ・日付・時間・大学ロゴを入力。
3. 右の「企画」で企画名・団体・場所を登録。「一括登録」でポスターを複数追加可能。未登録ポスター枠へ順に割り当て、余剰分は新しい企画として登録します。
4. 「企画一覧」と「学生企画」が同じデータから更新されます。ポスターは4件ずつ改ページします。
5. 「広告」で企業・規格・素材を登録。1/4広告はポスターページへ先に自動割当し、残りは対応規格の広告テンプレートに割り当てます。ページ右パネルで手動割当も可能です。
6. 左のページをドラッグして並べ替え。テンプレートの追加・複製・削除もできます。削除はそのテンプレートから生成した全ページが対象です。自動生成ページ数は企画件数で調整します。
7. 「デザイン」で章・色・綴じ方向・ページ数調整を設定。詳細編集で余白・本文サイズ・広告寸法を調整。
8. 「確認」の警告からページへ移動し、必要な修正と人手確認を実施。
9. 「ファイル保存」で素材ごと `.pamph` にバックアップ。「開く」で再編集できます。別名保存はプロジェクト名を変えて保存します。
10. 「PDF出力」でA5単ページの標準PDFを取得。

ブラウザの自動保存は永続保証がありません。引き継ぎ時には必ず.pamphファイルを別途保管してください。最近のプロジェクトから復帰でき、次年度への複製は元年度とは別のIDで作成されます。

## 実装したもの

- React / TypeScript / Vite、3カラム編集、A5単ページ・見開き、画面に合わせた表示とズーム。
- T01表紙、T03目次、T08企画一覧、T09ポスター4枚＋1/4広告、T16広告。T02お知らせ・T18裏表紙は基本的な画像／文章のみ。
- mmベースの共通描画リスト、左右外側のインデックス、章色・不透明度55%、物理順とは独立した連続ページ番号。
- 長文表の折り返し・自動改ページ・繰り返し見出し、ポスター1/4/5/11件の改ページ、広告不足警告・重複割当の検出。
- PNG/JPEG/WebP/PDF/SVGの一括登録、縦横比を維持した全体表示。PDF素材は1ページ目を登録。複数ページは事前分割が必要です。
- ZIP形式.pamph、原本素材同梱、IndexedDB自動保存、取り消し・やり直し、次年度複製、スキーマ検証と欠損素材の部分復旧。
- Web WorkerによるPDF生成。日本語文字・表・インデックス・図形はベクター、Noto Sans CJK JP Medium/Boldの静的TrueType版を全体埋め込み。
- PDF素材をForm XObjectとして直接埋め込み。SVGはsvg2pdf.jsでベクターPDFに変換して埋め込み。画面のスクリーンショットは使いません。
- A5境界・文字幅・素材参照・実効300dpi・広告未配置・規格相違・原稿比率のチェックと人手確認。

## 既知の制限・次の段階

- **出力はRGBの校正用PDFです。CMYK / ICC / PDF/X / トンボ / 塗り足し / アウトライン化 / 見開きPDF / 面付けは未実装です。** 印刷用としてそのまま入稿しないでください。
- T04〜T07、T10〜T15、T17の専用テンプレート、企画種別ごとのデータモデル、スタッフ管理、QR自動生成は次段階です。協賛企業名ソートのロジックはありますがT15のページUIは未実装です。
- デザイナーモードではテンプレートの自由配置・複製・再利用ができます。フォントのユーザー切替、英数字のArial指定、画像トリミング、企画自体の手動掲載順は未実装です。現在はNotoに統一します。
- ポスター下の名称は2行までの短縮表示で、長い場合は警告します。全文は一覧表に保持します。
- SVGは自己完結した図形・パスを対象とし、文字・スクリプト・外部参照・style要素は警告して拒否します。文字をパス化したSVGかPDFをご使用ください。
- 回転メタデータを持つPDF、暗号化／破損したPDFは出力できないことがあります。回転を適用した原稿へ変換してください。ラスターへの黙った代替はしません。
- 元PDF素材に含まれるフォントの埋込状況・透明効果・色空間は原本に依存し、人手確認が必要です。
- フォントのサブセット化に起因する欠字を避けるため全体を埋め込み、PDFは文字だけでも約23MBになります。性能・容量の最適化は今後の課題です。
- 元PDF完全同一の組版ではありません。2025年版の共通デザインを編集可能なパラメータで再構成しています。印刷会社での実機校正、Windowsでの実動作は未検証です。
- Tauri 2、OSファイル保存、インストーラー、旧スキーマからの実データ移行は次段階。保存インターフェースは差し替え可能に分離済みです。現在はschemaVersion 3を使用し、version 1・2を移行して読み込みます。未知の将来バージョンは誤変換せず拒否します。

構造・根拠は `docs/architecture.md`、参考PDFの分析は `docs/reference-analysis.md`、検証結果は `docs/testing.md` に記載しています。

## 2026-11-06 追加仕様の反映

広告の初期寸法は幅125mm、縦180／85／45mmです。1/2広告の高さ85mmは独立値で、180mmの半分ではありません。ポスター枠は添付原稿1052×1495pxの縦長比率に統一しました。詳細な開発状況と引き継ぎ情報は、圧縮していない `docs/開発状況と引き継ぎ.md` を参照してください。


## デザイナーモード（追加実装）

制作画面上部から開きます。A5上で図形・文字・画像・パスを編集し、テンプレートとして保存・適用できます。レイヤー、グループ、回転、整列、ガイド、スナップ、Undo/Redo、内部コピー・ペーストに対応しています。表・ポスター・時間割のデータ連動パーツと、インデックス・一段の共通マスターを使えます。テンプレートは素材を含む.pamptplでプロジェクト間を移動できます。

VectorCraft／DesignCraftはライセンスと構造を調査しましたが、本体のRust/WASMは未統合・実ビルド未検証です。今回のエディタは既存TypeScriptエンジンの拡張です。Illustratorの全機能を実装したものではありません。時間割は企画別のバー配置で、時間比例の会場レーンは今後の課題です。

- [操作・実装状況・制約・引き継ぎ](docs/デザイナーモード_実装と引き継ぎ.md)
- [OSSの調査と統合判断](docs/デザイナーモード_OSS調査と統合判断.md)
- [第三者素材とライセンス](THIRD_PARTY_NOTICES.md)

## UI/UX改善版

ダークテーマ、上部メニュー、縦型ツールバー、レイヤー／ページ／テンプレートの切替、選択対象別プロパティへ再構成しました。最初の画面から6種類のテンプレートを作成でき、用紙上への直接文字入力、画像選択配置、右クリック操作、仮データによる改ページ確認ができます。

作成と適用は「テンプレート」メニュー、外部保存とPDFは「ファイル」メニューです。保存は.pamph、テンプレート単体の移動は.pamptplを使用します。使用中のテンプレートを編集すると参照ページにも反映されます。

[現行UIの操作・実装・検証・残課題](docs/UIUX改善_実装と操作ガイド.md)を参照してください。指定3サイズでの画面検証と、67件の自動テスト、実際のPDF出力を確認しています。
