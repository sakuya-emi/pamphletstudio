# 学園祭パンフレット自動制作アプリ：開発状況と引き継ぎ

記録日：2026年11月6日。これはZIP等に圧縮していないMarkdownの文書です。ソースコードとともに通常のテキストとして閲覧・編集できます。実装済みの範囲、検証した事実、未実装の部分、仕様変更を分けて記載します。

## 1. 今回の依頼と実装範囲

依頼は、仕様書だけでなく、ローカルで動くReact・TypeScript・ViteのWebアプリを作ることです。最初に基盤、主要5テンプレート、基本的なベクターPDF出力を優先する指定がありました。現在はこの優先範囲を実装した初期Web版です。すべてのPhase 1要件や全18テンプレートが完成したとは扱っていません。

参考PDFを丸ごと画像として背景にする方式は採っていません。見出し、表、罫線、インデックス、ノンブル、素材枠をmm単位の編集可能な描画要素として再構築しています。ポスター・企業広告そのものは、ユーザーが登録した素材を縦横比を維持して配置します。

### 2026年11月6日の広告寸法の変更

| 広告区分 | 幅 | 高さ | 同一広告ページの最大件数 |
| --- | --- | --- | --- |
| 1ページ | 125mm（12.5cm） | 180mm（18cm） | 1件 |
| 1/2ページ | 125mm（12.5cm） | 85mm（8.5cm） | 2件 |
| 1/4ページ | 125mm（12.5cm） | 45mm（4.5cm） | 4件 |

重要な変更は、1/2ページを180mm÷2で計算しないことです。85mmを独立した寸法として保存・計算します。1/4ページも独立した45mmです。「1/2」「1/4」は広告の商品区分を表す名称として扱い、最大高さに掛ける倍率ではなくなりました。広告幅の旧初期値126mmは、新初期値125mmに変更しました。

広告ページの上下方向に使う範囲はy=20〜200mmです。標準の1/2広告2件は85mm＋10mmの間隔＋85mmで収めます。1/4広告4件は45mmずつです。T09では下部に125×45mmの広告枠を1件配置します。素材の実際の縦横比が枠と異なる場合は、全体を縮小して余白を付けます。素材を引き伸ばしたりトリミングしたりしません。この場合は警告を表示します。

詳細編集では各区分の高さを独立に調整できます。A5からはみ出さないよう、1ページは最大180mm、1/2は最大90mm、1/4は最大45mmに制約しています。印刷会社の指定変更に備えて寸法を固定定数だけに閉じ込めていません。

### 学生企画ポスターの縦長枠

追加された「御家坂46（2期生）ポスター.png」は1052×1495pxです。幅÷高さは0.7036789298で、およそ1：1.421の縦長です。T09の4枚の画像枠はすべてこの縦長比率を初期値として統一しました。未登録の場合のプレースホルダーも縦長です。

参考PDFの学生企画ページは縦長原稿を2列×2行で並べています。ただし、参考ページで実際に見える下部広告の高さを、そのまま今回の45mmと見なすことはできません。今回のA5上で45mmの広告を確保するため、4枚のポスターは参考ページより小さくなります。元画像の比率と画像全体を保持することを優先しています。

現在の標準寸法でのT09の計算は以下です。

- 本文の基準幅：126mm。左右のポスター列の間隔：5mm。
- ポスターとキャプションをまとめる1セル：60.5×59mm。
- セル内の画像枠：高さ49mm、幅約34.48mm。
- 画像枠はそれぞれのセルの水平方向中央へ配置。
- 上段の画像上端y=24mm、下段の画像上端y=88mm。
- 下部広告の上端y=153mm、下端y=198mm。
- 企画名・場所の文字とノンブルは画像とは別のベクター文字。

横長素材も読み込めますが、縦長枠の中に全体表示されるため上下に余白が生じます。勝手に縦長へ変形することはありません。学生企画用としては縦長の原稿を用意する運用を想定しています。

### 用紙・色・フォント

仕上がりはA5縦148×210mmです。マニュアルのA3指定は採用していません。A3等への面付けは別工程です。標準PDFはRGBの校正用で、CMYK印刷用PDFではありません。

文理マゼンタ#e4006e、文理オレンジ#ec6c1f、文理ブラック#231815、文理シルバー#808080を初期プリセットにしています。章ごとの色と本文背景は変更できます。

Noto Sans CJK JPのMediumとBoldを同梱しています。Arialは再配布していません。英数字も現在はNotoに統一しています。PDF内の文字はフォントを埋め込み、検索・コピーできる状態です。サブセット化では実レンダリング時に欠字を発見したため、静的TrueType版を全体埋め込みします。このため文字だけでも出力PDFは約23MBになります。これは品質確保のための現時点の実装上の選択であり、今後の容量最適化の対象です。

## 3. 実装済み機能の詳しい状態

### 起動と画面

ローカルサーバーで実際に起動しています。標準の操作はnpm install、npm run devです。macOS用start.commandとWindows用start.batも用意しました。Windows上での実機検証は未実施です。通常利用で外部APIやログインを要求しません。ローカルサーバーとブラウザは必要です。

ホームには新規作成、.pamphを開く、サンプル、最近のプロジェクト、次年度への複製があります。汎用的なテンプレート管理画面は未実装です。編集は左のページ、中央のA5プレビュー、右の内容・デザイン設定です。幅1024px以上のPCブラウザを推奨します。Codexの狭いサイドパネルでは横スクロールが必要です。

単ページ・見開き、ページ送り、ズームが動きます。取り消し・やり直しは最大40履歴をメモリ上に保持します。履歴そのものはファイルへ保存しません。ページの追加・複製・削除とドラッグによる順序変更ができます。自動生成ページの削除は、個別の画像を消す操作ではなく、元テンプレート全体の削除として案内しています。企画件数を減らすと、必要な生成ページ数も減ります。

### 登録データとテンプレート

企画名、団体名、建物、階、教室、開催場所、ポスターをひとつのEventとして保持します。同じEventから一覧表とポスター紹介を生成し、二重入力を避けています。

T01表紙：開催回数、学園祭名、テーマ、日付、時間、メイン画像、大学ロゴ。大学ロゴ未登録を警告します。

T03目次：章の開始ページを参照し、最終順序とノンブル確定後に参照番号を描画します。章数に応じて目次自体の改ページ数を先に確定するため、参照番号の再計算が無限に循環しません。

T08企画一覧：建物、階、教室番号の順に整列し、団体名と場所も表示します。行の文字を折り返し、長い行はページをまたいで保持します。続きページには表見出しを繰り返します。

T09ポスター：4件ずつ改ページ。11件なら4・4・3件です。縦長の均一枠、名前、場所、下部の1/4広告を生成します。空き枠を残すか最後の1枚を中央に寄せるか選べます。長い企画名は2行の短縮表示とし、警告します。全文は一覧表に保持します。

T16広告：登録した規格の広告を自動配置します。手動割当もできます。未設定枠を警告し、不足を埋めるための広告の自動重複はしません。同じ広告の重複手動割当と規格の不一致はエラーです。

T02お知らせ・T18裏表紙は基本的な画像と文章の配置だけです。QRやアクセス地図を専用フィールドで扱う完成版ではありません。

### 保存と復元

.pamphは原本素材を含むZIP形式のプロジェクトファイルです。ブラウザ内にはIndexedDBで自動保存します。ブラウザ内保存が消える可能性があることと、外部ファイル保存が必要なことを画面に表示します。

現在のスキーマはversion 2です。version 1のファイルとブラウザ内データは、独立した広告高さと縦長ポスター枠を追加して読み込めます。旧初期広告幅126mmは125mmへ更新します。独自に設定された別の広告幅は保持します。version 1の半広告は新しい85mmへ移行します。元のファイルは上書きしません。ファイル読込時には形式更新をメッセージで知らせます。未知の将来バージョンは拒否します。

JSONや寸法などの不正は読み込み時にエラーにします。ZIP内の素材が一部欠けている場合は、復元できる情報を読み、素材欠損の警告を残します。壊れたファイルから何でも復旧できる機能ではありません。

### PDFと素材

PNG・JPEG・WebP・SVG・PDFを受け付けます。複数追加は未登録ポスターのある企画へ順に割り当て、余剰分は新企画を作ります。素材1件の上限は60MBです。

PDFのサムネイルはPDF.jsで生成します。出力では元PDFをpdf-libでForm XObjectとして直接埋め込みます。SVGは自己完結した図形とパスを対象に、svg2pdf.jsでベクターPDFに変換して埋め込みます。画面のスクリーンショットはPDF出力に使いません。

複数ページPDFは1ページ目だけを登録し、その旨を知らせます。複数ページは事前に分割してください。回転指定付きPDFは出力時にエラーにします。SVGの文字、外部参照、スクリプト、style要素は拒否し、パス化したSVGかPDFを案内します。黙って画像に変換する代替は行いません。

生成処理はWorkerで実行します。登録画像・SVG・PDFを混ぜた8ページのPDFを、実ブラウザからダウンロードできました。原本PDFに含まれるフォント・透明効果・色空間まで自動修復するものではありません。

## 4. 自動チェックと人の確認

A5境界外、長い文字の幅、素材参照切れ、300dpiを目安とした実効解像度、広告未配置、広告規格相違、広告の比率違いをチェックします。指摘されたページへ移動できます。誤字、地図の必須事項、素材の使用許可、タイムテーブル備考は人が確認する項目です。

「すべて確認済み」でも印刷用PDFへの適合が保証されるわけではありません。CMYK変換、ICC、PDF/X、塗り足し、トンボ、アウトライン化、面付けは未実装です。

## 5. 検証内容と結果の保管場所

自動テストはtests/layout.test.tsです。広告規格変更前の24件に、旧スキーマ移行とポスターの縦長比率・125×45mm枠を検証する2件を追加しました。26件すべて成功しました。最新の実行結果はdocs/testing.mdにも記録しています。

PDFの構造検査はtests/verify_pdf.py、結果はdocs/pdf-verification.txtです。テストPDFはoutput/pdf/verification.pdfです。日本語の文字抽出、埋込フォント、全ページのA5寸法、元PDFのForm XObject保持を確認します。Popplerで実際にページ画像へレンダリングし、目視も実施しています。抽出テキストだけで品質を判断していません。

追加された御家坂46のポスターも実画面で登録し、縦長枠内に切り抜かず配置できることを確認しました。

ブラウザでは新規・サンプル・自動保存復帰・企画追加・複数素材登録・PDFダウンロード・.pamphダウンロード・保存ファイルからの再読込を確認しました。UIのスクリーンショットはdocs/screenshots/editor.pngです。

## 6. 次の担当者が着手する順番

1. 新しい125×180／85／45mm広告と縦長枠を大学側で校正し、ポスターの実寸が読めるか実印刷で確認する。現在のT09の画像枠は約34.48×49mmなので、小さい文字を含む原稿は拡大掲載など別テンプレートが必要になり得ます。
2. 実際の学生ポスターと協賛広告を十分な件数登録し、長い企画名・建物名・広告比率の違いを検証する。
3. 残りの専用テンプレートとデータモデルを追加する。挨拶、注意事項、タイムテーブル、マップ、模擬店、キッチンカー、ステージ、1ページ企画、外部団体、協賛企業一覧、スタッフを対象にする。
4. フォントの一括切替、企画の手動掲載順、画像の個別調整、テンプレート管理、年度更新時にどの共通素材を保持するかの細分化を実装する。
5. 初期読み込み容量とフォント埋込容量を最適化する。欠字を再発させないよう、必ず実PDFをレンダリングして比較する。
6. 印刷会社のICC・PDF/X・塗り足し条件を確認してから、標準PDFとは独立した変換・適合検査工程を実装する。
7. Web版の校正を終えた後にTauri 2へ移行し、WindowsとmacOSの実機でファイル操作・日本語フォント・オフライン動作・インストーラーを検証する。
