# Excel雛形 v4（2026-11-27）

本番記入用は `public/templates/Pamphlet-Studio-Excel-template-v4.xlsx`、参照用の架空データは `Pamphlet-Studio-Excel-template-v4-example.xlsx`。いずれも「はじめに」と15入力シートの全16シートを含む。アプリ内に両方のダウンロードリンクを設けた。

## 記入体験

- 「はじめに」に全シートの役割、記入順、必要な場合だけ記入する区別、必要項目、保存・取り込み、間違いやすい操作を記載。
- 入力順にタブを整理。青は参照用、緑は入力用。黄色は本番入力欄、薄橙色は架空記入例。案内3行と見出しを常時表示するウィンドウ枠固定、列幅・折り返しを設定。
- 見出しと基本情報の項目名は保護し、入力セルだけ編集可能。通常シートは5〜204行の200件分。基本情報は固定6項目、アンケートは1件。誤操作防止の保護でパスワードなし。200件を超える場合は別ファイルに分ける。
- ポスター要否は「要／不要」、広告サイズは「1ページ／1/2ページ／1/4ページ」、お知らせの種類は「お知らせ／注意事項」のプルダウン。入力規則のエラー形式は停止。ポスター空欄は従来どおり「要」。
- 開催日は `yyyy-mm-dd`、企画時刻は24時間制 `HH:MM` で表示し、日付・時刻の入力規則と例を掲載。開催時間の範囲は文字列として案内。記入例の全角時刻・英語広告サイズを正式形式に統一。
- アンケートは「アンケートURL」の見出し直下に大きな入力欄とコメントを設置。説明を最上部に表示し、http(s)で始まる2048文字以下のURLという入力規則を設定。任意の見出し・本文、全欄空なら既存情報を保持することも明記。
- 貼り付けはExcelの入力規則を回避・上書きする場合があるため、ガイドで値のみ貼り付けと再確認を案内。アプリ側の既存取り込み検証も継続。

## 互換性・確認

シート名・見出し名は維持。既存の見出し探索により、v3の1行目見出しとv4の4行目見出しの両方に対応し、見出しの読み取り処理は変更不要。タブ並べ替えだけで新規企画の追加順・誌面順が変わらないよう、登録処理順をv3相当（協賛企業を先行）に固定した。v2・v3も残している。

実ファイルをChromium上でアプリの `readWorkbook` → `interpretRows` → `planRow` → `layoutProject` に通して比較した。v3とv4記入例はともに60件・エラー0件・28ページで、登録内容とページ内の描画要素が一致。両方のアンケート欄に同じURL・見出し・本文を記入した場合も61件で一致。空欄版は認識0件で架空情報の混入なし。アプリと共通の登録順序関数を使用し、タブ順の異なる実ファイルで比較した。

アプリ画面でも、両版のダウンロードが配布元とバイト単位で一致し、v4記入例の読み込みから登録まで完了することを確認した（ブラウザーエラーなし）。全249テストと公開パス指定の本番ビルドが成功。

回帰テスト `tests/excel-template-v4.test.ts` では実XLSXを開いて見出し、ガイド、保護、入力規則、認識件数、登録内容、ページ構成を確認する。Excelデスクトップでの直接操作はこの環境では未確認。プルダウンの停止設定・入力セルのロック解除は保存済みXMLで確認した。

## 再生成

Python 3とopenpyxl 3.1以上を用意し、リポジトリ直下で実行する。

```sh
python scripts/generate-excel-template-v4.py
```

既存v3を元データとして空欄版と記入例版を生成する。アプリの表示系残件・SPEC-A/E/Iは今回の変更に含めない。
