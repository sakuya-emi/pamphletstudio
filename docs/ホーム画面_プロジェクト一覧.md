# ホーム画面の変更

2026-11-07

紹介文（TOYU FESTIVAL / EDITOR、キャッチコピー、説明文）と大きな開始ボタン領域を削除しました。左上を「新規作成」とし、残りを表紙のサムネイル・プロジェクト名・年度・保存日時を持つカラム表示にしています。サムネイルは登録された表紙デザインと素材から描画します。表紙がなければファイルアイコンを表示します。編集画面のデザインやPDF出力は変更していません。

PC内の.pamphは「.pamphを追加」で複数選択、または「フォルダから追加」で取り込みます。.pamph以外は読み込みません。ファイルごとに読み込み、失敗したファイルがあっても正常なものは一覧に追加します。同じプロジェクトIDでブラウザ内のデータのほうが新しい場合は、古いファイルで上書きしません。最近のプロジェクトの8件制限は外しました。

ブラウザはPC内の全フォルダを無断で走査できないため、最初にファイルまたはフォルダを選ぶ必要があります。フォルダ選択に対応しない端末は、ファイルの追加を使ってください。元のPC上のファイルを直接変更する方式ではなく、読み込んだデータをブラウザ内に保持します。編集後は従来通りファイル保存で.pamphを出力します。Macとスマホ、異なるブラウザやURLでは、ブラウザ内の保存一覧は共有されません。

検証：型チェック、本番ビルド。実ブラウザで紹介文が消え、左上に新規作成、表紙プレビューのカラム一覧が表示されることと、.pamph追加が一覧に反映されることを確認しました。

変更ファイル：apps/web/src/App.tsx、apps/web/src/ProjectHome.tsx（新規）、apps/web/src/style.css、packages/project-storage/index.ts。本書は通常のMarkdownです。

追加調整：一覧は画面幅を使い切り、収まらないタイルは次の段へ自動で折り返します。スマホは2列、非常に狭い画面は1列です。
