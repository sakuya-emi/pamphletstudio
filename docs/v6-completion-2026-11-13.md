# v6 完了管理・自動ページ調整

現行ソースでは、PDF完了状態はReact内にしかなく再開時に消えた。手動確認は未確認時に警告へ混入していた。中綴じ白紙は裏表紙直前のスタッフ見開きを優先してその前へ入る仕様だった。公開サイトはWebツールで取得できなかったため、操作確認にはローカル版を使用した。

- 最後の成功したPDFの日時、実PDFのページ数、冊子内容の識別子を保存。内容編集で識別子を更新し、再出力まで旧履歴は保持する。確認チェック自体は識別子を変更しない。年度更新では旧履歴を持ち越さない。
- スキーマ5の任意項目として読み書きする。古いファイルには履歴がなく、既存のページ数設定は維持する。新規冊子は4の倍数を既定にする。
- 自動調整ページは開始位置と総ページ数を区別する。後者は裏表紙の直前。スタッフの2枚はペアを維持するが、調整白紙があればスタッフと裏表紙の間に入る。
- 既存の複数行削除確認とUndoを維持した。「元に戻す」はタイマーで消さない。別の編集をした場合は専用ボタンを外し、履歴の「取り消し」で戻す。
