# 制作手順と開催日の改修（2026-11-09）

新規作成と次年度への複製は「デザインを選ぶ → 情報を入力 → 紙面確認 → チェックと出力 → 入稿前チェック」の順で進む。既存プロジェクトは紙面確認から再開でき、上部の手順からデザイン・基本情報へ戻れる。緑は完了、黄は要確認、白枠は現在の手順。作業ページとデザイナーモードは従来通り利用できる。上部の詳細設定切り替えは非表示とした。

ステージの見開きは開始時刻順に最大12件ずつ処理する。左と右の件数差は最大1件で、それぞれのページの枠幅は均等。時間軸はノドでつながり、終了時刻の長さで枠幅は変わらない。

開催日は新規作成・次年度複製で未入力。単一の日付を入力すると、その日付を基準に年度と曜日をそろえる。旧ファイルも読み込み時に単一の日付を補正する。複数日など、単一の日付として判定できない旧表記は保持する。保存形式の変更・削除対象はなし。

自動テスト169件、TypeScriptとViteの本番ビルド、ブラウザで新規作成から入稿前チェックまでの遷移を確認。PDFは既存の校正用RGB出力。公開サーバーは未更新。
