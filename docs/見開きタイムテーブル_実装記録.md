# 見開きタイムテーブル 実装記録

更新日：2026-11-07

## 実装内容

ステージタイムテーブルの横時間軸を、左右2ページに共通する1本の時間軸として組版する。ステージ企画・学生ステージ企画の登録内容を使用し、全見開きで時間範囲を共通化する。重なる企画は別の段に配置し、企画名は縦方向に表示する。中央にかかる図形は分割し、文字は綴じ目を避けて片側へ配置する。

横時間軸では見開きを標準とする。デザイナーの「見開き2ページに1本の横時間軸」を解除すると従来の単ページにできる。縦時間軸は単ページを維持する。新しい横時間軸プリセットを追加し、既存テンプレートの参照を保持する。

見開きの左右は綴じ方向から判断し、必要な場合のみ開始位置調整ページを挿入する。手動ページ順でもペアが分離しないようにする。PDFは従来の描画エンジンでA5単ページを出力する。文字・図形のベクター出力とフォント埋め込みを維持する。

## 保存と互換性

テンプレートに任意のspread設定を保存する。従来の横ステージテンプレートで未指定の場合も見開きを標準とし、明示的なfalseは単ページとする。登録企画・画像・広告・既存IDを変更しない。.pamphのZIP構造は変更しない。

## 現時点の制約

デザイナーの編集アートボードは従来のA5単位。左右の完成表示は制作モードの「見開き」で確認する。見開き全面を1枚の自由配置アートボードとして編集する機能は今回追加していない。

長い企画名が枠内に収まらない場合は、既存の補足ページへ全文を掲載する。中央をまたぐ企画の時間枠は両ページに分かれ、文字は片側に寄せて表示する。印刷用CMYK/PDF/X処理は今回の変更対象外。
