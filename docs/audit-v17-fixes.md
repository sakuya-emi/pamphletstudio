# 表示と導線の再検証

## 対応

- **少数企画のタイムテーブル**：6件以下で内容が収まる場合、左右各2件の見開きに分けず、開始・終了時刻、企画名、団体・場所・備考を横書きカードで1ページに配置。4件の検証データでは1ページに全4件を掲載し、カードをページ下部まで配置します。長い内容や7件以上では従来の配置に戻します。
- **既存デザインとの互換**：新しい初期配置をコンパクトとし、ステップ1に「コンパクト（6件以下は1ページ）」を追加。明示的に選択済みの「色帯と縦書き」「細い時間軸と縦書き」は保持。既存の縦書きを切り替える場合は、ステップ3でタイムテーブルを開き「タイムテーブルをコンパクトにする」を押せます。
- **学生ステージの未登録枠**：既存タイムテーブルに掲載されるステージ企画は、画像未登録だけの紹介ページを生成しません。画像を追加すると紹介ページを作ります。登録が必要な画像の警告と画像登録フローは維持します。
- **箇条書きの実際の導線**：ステップ3上部に「箇条書きを選ぶ」を追加。現在の本文ページ、なければ適用可能な本文ページを選び、箇条書きカードの選択と適用ダイアログを直接開きます。案内文もこの実在するボタン名に合わせました。
- **進捗の整合**：画面に使う進捗は、描画済みページ数÷総ページ数の四捨五入に統一。5/32なら16%、32/32なら100%で、数値表示とバーに同じ値を使用します。旧来の90%・95%に重み付けした値はWorkerからUIへ送りません。描画100%とファイルの仕上げは区別し、ダウンロード完了後にも保存完了を表示します。
- **広告追加後の白紙内訳**：通知に総ページ数と自動白紙数の増減に加え、「章・見開きの開始位置調整」と「総ページ数調整」のそれぞれのページ数を表示。

## 検証

- 全247件・34ファイル成功。新規に少数企画の1ページ配置、未登録だけのステージ紹介ページの除外、5/32＝16%・32/32＝100%での表示とバーの一致を確認。
- 旧来の縦書き・時間軸のテストは、明示的にそのスタイルを選択した場合に保持されることを引き続き検証。
- `/pamphlet-studio/` 向けの型チェック・本番ビルド成功。
- ChromiumでExcel取り込み後、ステップ3の「箇条書きを選ぶ」→「アクセント」→「このデザインを適用」を実際に操作。保存された冊子に箇条書き部品が適用されていることも確認。
- ブラウザでタイムテーブル1ページ、重複した式典紹介ページ0件、進捗バーが0から100まで進むこと、広告追加後の白紙内訳通知、PDFダウンロードを確認。未処理JavaScriptエラー0件。

対象は検証用の新規冊子です。オーナーの既存プロジェクトは操作していません。SPEC-A/E/Iは変更していません。
