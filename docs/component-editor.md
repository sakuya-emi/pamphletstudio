# 部品を編集する画面

共通デザイナーでは部品を選ぶと、その部品の設定を優先して表示します。表は列境界をドラッグでき、右側で列幅・行間隔・本文の文字サイズ・行罫線を調整できます。個別セルなどの設定は「表・セルの詳細設定」にあります。

左の「作図ツールを開く」でペン、制御点、図形などを表示します。部品単体のテンプレートは既存仕様で対象部品1個のため、「この配置で作図する」で独立したページデザインへコピーします。画面とキャンバスは共通で、元の部品や適用済みの冊子は変わりません。ページデザインでは既存の作図ツールを直接使えます。

保存形式・PDFエンジンは変更していません。TypeScriptと本番ビルド、既存テストを実行しました。今回のブラウザ操作確認は未実施です。
