# 部品テンプレートと表デザインの実装記録

更新日：2026年11月6日。今回の変更を記録した通常のMarkdown文書です。ZIPにまとめず、ソースと同じフォルダで読めます。過去の実装記録より、この文書の記載を優先してください。

## 今回の到達点

既存のReact / TypeScriptアプリを拡張しました。外部APIは不要です。A5縦148×210mm、広告125×180 / 125×85 / 125×45mm、縦長ポスター、共通NodeからSVG・ベクターPDFを生成する構成を維持しています。

最優先の「部品を適用するとページ全体が置換される」問題を修正しました。部品はBlock.componentsに保存し、ページを参照するBlock.templateIdと分離しています。対象IDと種類を使い、既存の配置・バインディング・ページ固有の上書きを保持します。インデックスの適用で表、広告、背景、見出し、ページ番号、企画情報、章情報を変更しません。対象がなければダイアログで新規追加を明示的に選択します。

## 使い方

初回は「デザイナーモード」を開くと初期ライブラリが登録されます。

1. 制作モードで企画一覧ページを選択します。企画名などは「企画」から登録します。
2. 右のデザインバリエーションから「表A」「表B」「表C」またはインデックスを選びます。部品のみのテンプレートには「部品のみ」と表示されます。
3. 「部品だけを変更」で対象と範囲を確認して適用します。同種部品の全ページ適用、カスタムページの共通マスターへの適用も選べます。
4. デザインを調整するときは「デザイナーモード → 既存テンプレートを編集」で、左のテンプレート一覧から選びます。
5. 表をダブルクリックすると内部編集に入ります。セルをクリックし、右の「編集対象」で行・列・セル・見出し・グループ枠・グループ見出し・罫線・タイトルを選びます。列間の灰色の境界をドラッグすると列幅が変わります。
6. 色コードはEnterまたはフォーカス移動で確定します。数値は変更時に反映します。Escでセル→表全体→内部編集終了と戻ります。
7. 四隅の角丸はmmです。「角丸を連動」をOFFにすると個別に設定できます。過大な値は隣り合う角の合計を基準に同じ比率で縮小します。
8. ファイル → テンプレートを書き出す／読み込む、で.pamptplを共有できます。プロジェクト全体は.pamphで保存してください。参照している部品デザインを変更すると、その参照先の制作ページにも反映されます。別案を残す場合は先に複製します。

部品の編集時は現在の制作ページを薄く表示します。サンプル件数の切替は登録情報を変更しません。PDF出力は実際の登録情報を使います。

## テンプレートの区分と互換性

| 区分 | 用途と実装 |
| --- | --- |
| page | ページ全体の構成、背景、部品配置 |
| component | 表・インデックスなど1つの自動組版部品。ページ全体の参照を書き換えない |
| master | 共通要素。ページから参照し、ページ固有の部品上書きとは別に保持 |
| style | 選択オブジェクトの外観の保存・適用。配置や本文は保持 |

スキーマを4へ更新しました。形式1・2・3を読み込み、形式3の単一radiusを四隅へ移行します。既存の固定ページ、既存の表の組版は残し、高度な表スタイルがある場合だけ新エンジンを使います。旧テンプレートのscope未指定はページ扱いです。未参照の旧インデックス専用テンプレートは部品へ変換しますが、既にページとして使われているものは勝手に削除・変換しません。

.pamphには部品参照、配置、個別設定、セル書式、結合、四隅、章設定、素材を保存します。.pamptplは単独で使えるよう、オブジェクトが参照する部品の外観を編集可能な要素へ展開して書き出します。元プロジェクトへのライブ参照は引き継ぎません。

## 3つの表

添付画像の番号と本文のA/C説明が入れ替わっているため、番号ではなく特徴を基準にしています。画像自体を貼り込んではいません。

| 表 | 内容 |
| --- | --- |
| A：ストライプ＋縦結合 | 左に青い建物結合セル、中央に青い場所列、右に緑の企画名。列別の交互背景、上下端の角丸 |
| B：グループカード＋点線 | 建物別の角丸枠、控えめなベクターの影、左に大きい建物名、企画名と場所の各行に点線。建物別の枠色 |
| C：分割カラム＋結合セル | 模擬店タイトル、企画名・団体名・場所の3列、列の隙間、水色ストライプ、共通場所の縦結合 |

スタイルの優先順位は「基本 → 奇偶行 → 行 → 列 → セル固有」です。列の交互色、ヘッダーの列別設定も持てます。横・縦・矩形の明示結合と、データ項目による連続行の自動結合があります。隣接罫線は同一直線上の端点で分割して1本を選ぶため、結合セルの長辺と複数の短辺の重複にも対応します。セル固有の線を優先し、同順位なら後に登録した辺を採用します。

改ページでは見出しと建物名を再表示し、巨大なグループは継続ページへ分割します。「可能な限り分割しない」は、グループ全体が新ページに収まる場合に次ページへ送ります。枠の最小高さには建物見出しと継続表示の高さも含めます。1ページより大きいグループは分割します。極端に長い単一データ行は全文を保持して複数の断片に分けます。文字を無断で極端に縮小しません。

点線は文字のベースライン上ではなく行の下側へ配置します。SVGとPDFの線種を共通にし、PDFライブラリが初期化する線種も描画オプションとして明示します。

## 未実装・制約と次の順序

今回の依頼全項目を完成扱いにはしていません。優先度1〜4を中心に実装し、以下は残っています。

1. 部品テンプレートは現状1つの組版オブジェクトです。任意の装飾図形を複数含めた複合部品の作成、内部図形の完全な自由配置は次の拡張です。ページ・共通マスターでは従来の複数図形編集が可能です。
2. 四隅は長方形・表・セル・ヘッダー・グループ枠・タイトル・インデックスに対応します。ポスターや広告原本のクリッピングには未対応です。広告を無断で切り抜きません。
3. 自動行高OFFでも文字を欠落させないため長文では拡張します。厳密な固定行高＋オーバーフローの選択UI、改ページOFF、任意フォントのセルごとの切替は未実装です。1ページ以上の長文を単一の結合セルに詰める場合の完全な分割制御、重なる明示結合範囲の編集支援も追加検証が必要です。
4. グループ別の枠・色・影は編集できますが、グループ内の行スタイルを独立した階層として持つ機能は未実装です。行・列・セル書式で個別調整します。フォントは同梱Noto Medium/Boldを使います。
5. インデックスの四角・全角丸・外側角丸・上側・下側・斜め・正規化SVGパスに対応しました。SVGパスは絶対M/L/Q/C/Zのみです。章ごとの詳細プロパティUI、タブを直接選んで個別編集、状態別の全プロパティ、任意SVG全命令への対応は残っています。非選択55%と見開き外側配置は維持します。
6. タイムテーブル5形式、星形・多角形、パスの結合・分割、グラデーション、クリッピングマスク、一般図形の影は未実装です。今回の優先度が高い部分の検証を先に進めました。
7. スタイルプリセットは保存と選択オブジェクトへの適用が中心です。専用スタイルエディタと多項目の管理は未実装です。テンプレート削除時、直接オブジェクト参照は外観を展開しますが、ページの部品インスタンスは解除して標準デザインへ戻します。
8. 旧テンプレートのページ全体から部品への自動認識、全ブラウザ・Windows/macOS実機の検証は完了していません。
9. CMYK/ICC/PDF/X・面付け・塗り足し・デスクトップ化は引き続き未実装です。フォント全体埋込みによるPDF容量、Viteの大きいチャンク警告も残っています。

次は、複合部品とポスター・広告枠の非破壊マスク、結合セルの極端な長文、章タブ直接編集、タイムテーブルの順で拡張します。

最終確認：型チェックとVite本番ビルド成功。ブラウザのconsole error記録は0件でした。101件の全体テスト成功後、継続ラベルの表記調整を行い、部品テスト34件を再確認しています。
