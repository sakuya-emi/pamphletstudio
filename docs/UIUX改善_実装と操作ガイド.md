# パンフレットエディタ UI/UX改善：実装・操作・検証記録

更新：2026-11-06。ユーザーの「パンフレットエディタ UI/UX全面改善指示書」に基づく改修の記録です。通常のMarkdownで保存しており、文書の閲覧に解凍やアプリは不要です。前回のデザイナーモード初期実装の記録と区別して、本書を現行UIの操作ガイドにします。

## 変更の目的と範囲

配色だけでなく、テンプレートの作成・編集・保存・適用の導線、パネルの役割、ツールの操作、プロパティの優先順位を変更しました。制作モードは内容登録、デザイナーモードは繰り返し利用するデザインの編集という分担です。既存の登録データ、広告規格、A5の描画座標とPDF出力方式は保持しています。

画面は黒・チャコール・白を基調にしました。編集UIの背景は#111317、パネルは#1B1E23、入力は#292D34、境界は#39404B、文字は#E1E7EFと#9AA6B5、選択背景は#3A3E45、選択の境界は#858B94です。ツール・レイヤー・タブ・フォーカス・オブジェクト選択に水色は使いません。パンフレットそのものの章色・図形色は登録内容に従い、UIのテーマ色と独立しています。

制作モードの既存CSSも元の宣言を編集してトークン化し、文字を小さすぎないサイズへ調整しました。デザイナー用の古いスタイル群は削除し、editor/editor.cssへ置き換えました。style.cssの末尾に新旧のデザイナースタイルを積み重ねる構成にはしていません。

## 画面の構成

- 上部メニュー：ファイル、編集、オブジェクト、表示、テンプレート、ヘルプ。頻用する保存、取り消し、やり直しだけを常設アイコンにしました。
- 左端：選択、ダイレクト選択、ペン、長方形、楕円、直線、文字、画像、手のひら。Lucideの統一した線画アイコンと、名称・キー・説明を含むツールチップです。
- 左パネル：レイヤー／ページ／テンプレートのタブで役割を分けました。テンプレートは種類で絞り込みでき、サムネイルを表示します。
- 中央：白いA5アートボードとチャコールの作業領域。mmルーラー、全体表示、拡大縮小、ガイド・グリッド、データ確認ページがあります。
- 右パネル：選択対象専用のプロパティ。位置・サイズ・外観は折りたたみ、表・インデックス・時間割・ポスター・文字の設定を優先します。対象が変わるとパネルを先頭へ戻します。
- 下部：ツール、選択数、ズーム、ブラウザ保存状態、操作結果・警告、短い操作ヒントを表示します。

ページパネルは「ページ生成のまとまり」で一覧化し、各項目に生成ページ数を表示します。自動改ページする表などの途中の1枚だけを独立編集する方式ではありません。項目の追加・複製・削除・前後への移動に対応します。カスタムテンプレートのページを選ぶと編集対象を切り替え、標準ページを選ぶと制作モードで開きます。制作モードの物理ページ一覧とドラッグ移動も維持しています。

## 作成・編集・保存・適用

デザイナーモードを開くと開始ダイアログを表示します。

1. **新しいテンプレートを作成**：表、インデックス、タイムテーブル、ポスター紹介、広告、自由配置を選びます。名前を指定し「作成して編集」で、用途に応じた初期オブジェクトを持つA5を開きます。
2. **既存テンプレートを編集**：左のテンプレート一覧から選びます。制作ページが既にカスタムテンプレートを使っていれば、そのテンプレートを編集対象として開きます。
3. **現在のページから作成**：制作モードのページの見た目を固定図形へ取り込みます。元の表を自動的にデータ連動部品へ認識し直す機能ではありません。

「作成」は新しいIDのデザインを追加し、「編集」はそのデザインを変更します。変更はプロジェクトに即時反映され、IndexedDBへ自動保存します。既にそのテンプレートを参照する制作ページにも編集が反映されます。独立した下書き・公開の二段階ではありません。

**保存**は「ファイル → プロジェクトを保存」または上の保存アイコン、Ctrl/Cmd+Sです。素材込みの.pamphファイルをダウンロードします。ブラウザ保存だけで引き継がず、このファイルを保管してください。テンプレート単体の移動は「ファイル → テンプレートを書き出す／読み込む」で.pamptplを使用します。

**適用**は「テンプレート → 選択ページのデザインを変更」です。登録した企画・画像・本文・ページの見出しは保持し、参照するデザインを切り替えます。新規テンプレートは適用するまで既存ページを置き換えません。「新しい制作ページに追加」はページ構成へ新しい項目を追加します。適用とテンプレート削除には結果を示した確認を設けました。オブジェクト削除はUndoで戻せます。

通常制作モードでは、ページの「デザインバリエーション」のサムネイルから選ぶだけです。多数の候補が入力欄を押し下げないよう、候補領域をスクロール可能にしました。

## 日常の操作

### 文字

Tを選び、用紙をクリックすると用紙上に直接入力できます。クリックの既定フォーカス処理によって入力欄が即座に閉じる不具合を修正しました。Ctrl/Cmd+Enterか別の設定欄への移動で確定、Escで入力中の変更をキャンセルします。文字をダブルクリックして再編集できます。

右パネルで文字内容、サイズ、太字、文字色、行間、左・中央・右揃えを変更できます。フォントは現在Noto Sans CJK JP固定で、埋め込みを示した読み取り欄です。未実装のフォント選択を有効な機能のようには見せていません。

### 図形と画像

長方形・楕円・直線はドラッグで作成、Vで選択して移動、ハンドルでサイズと角度を変更します。Shiftクリックで複数選択、Deleteで削除します。右クリックには複製、グループ化／解除、前面／背面、削除を用意しました。二つ以上を選んだときに整列を使用できます。

画像ツールは用紙をクリックするとファイル選択を開き、選んだ画像をその位置へ配置します。画像のアスペクト比は保持します。画像の表示に使わない塗り・線の項目は表示しません。選択解除後に新規配置するときは、前面側の表示・編集可能なレイヤーを対象とします。

### レイヤーとグループ

レイヤーの名前、表示、ロック、前面・背面への移動を操作できます。レイヤー配下にオブジェクトを表示し、グループは子要素を持つ折りたたみ表示です。グループの行で全体、子の行で個別要素を選べます。オブジェクト名は右パネルで変更できます。入れ子グループは従来と同じく非対応です。

### 表・インデックス・時間割・ポスター

表を選ぶと、見出し行高、最小行高、余白、文字サイズ、見出し背景・文字、交互背景、建物別見出し、列名・データ・幅比率を表示します。色はカラーピッカーとカラーコードの両方を使用できます。

インデックスを選ぶと章数、角丸、四角／角丸、各章色、間隔、縦方向の文字、非選択時の透明度、左右反転を表示します。章色の変更はそのプロジェクトの章へ反映します。

時間割を選ぶと方向、件数、ラベル文字サイズ、企画間隔、ラベル余白、配色を表示します。ポスターを選ぶと列・行・間隔と文字サイズを表示します。どちらも既存の組版エンジンを使用します。時間割は比例時間軸・複数会場レーンまで拡張したものではありません。

上の「プレビューデータ」で実データまたは0／5／11／30件の仮データを切り替え、自動改ページと繰り返し見出しを確認できます。仮データは保存情報を変更せず、PDF出力は実データを使用します。その違いはステータスにも表示します。

### キーボードと表示

V選択、Aダイレクト選択、Pペン、T文字、M長方形、E楕円、L直線、I画像、H手のひら。Spaceを押しながらドラッグで一時パン、Ctrl/Cmd+ホイールでズーム、通常ホイールでスクロールします。ズームのホイール処理はブラウザの既定ズームと競合しないよう非passiveイベントで処理します。「全体」でA5を作業領域内へ収めます。

Ctrl/Cmd+ZでUndo、Shift+Ctrl/Cmd+ZでRedo、C／Vで内部コピー・ペースト、Dで複製、Gでグループ化、Shift+Gで解除です。テキスト欄への入力中はエディタのツール切替・削除を抑止します。未定義の修飾キー操作は勝手に描画ツールへ変換しません。外部アプリのベクタークリップボード互換は未実装です。

## コードの分割

apps/web/src/editor/ に以下を分離しました。

| ファイル | 責務 |
| --- | --- |
| EditorShell.tsx | 外枠、ステータスバー |
| MenuBar.tsx | コマンドメニュー、外側クリック・Escによる閉じ処理 |
| ToolBar.tsx | 共通アイコン、キーとツールの説明 |
| LayerPanel.tsx | レイヤー、グループ、オブジェクトの階層操作 |
| PagePanel.tsx | 制作ページのまとまりの管理 |
| TemplatePanel.tsx | 絞り込み、サムネイル、編集対象選択 |
| Canvas.tsx | SVGアートボード、選択表示、直接文字入力、パンとホイール |
| PropertiesPanel.tsx | 選択対象の専用設定 |
| EditorDialog.tsx | 開始・新規作成・ヘルプ |
| commands.ts | 用途別初期テンプレート、削除、重なり順の操作 |
| editor.css | デザイントークンと各領域のスタイル |

Designer.tsxはプロジェクトへの変更通知、履歴、ツールと編集セッション、ポインター操作の調整を担います。全てを巨大な一つの表示コンポーネントに残す構造は解消しましたが、ポインター操作と履歴のロジックは引き続きDesigner.tsxに残っています。完全に独立した編集状態ストアへ移行済みという意味ではありません。

## 保存とPDFへの影響

schemaVersionは3のままで、文字の行間・揃えを省略可能なプロパティとして追加しました。旧データには行間1.5、左揃えを補い、旧版の固定テンプレートと.pamphを引き続き読み込めます。

制作モードへ戻ったときに古いResizeObserverが外されたキャンバスを計測し、プレビューが最小幅170pxへ縮む問題を修正しました。モード変更に合わせて観測を解除・再登録します。

PDF目視検証で、Latin文字で始まる日本語混在テキストの数字がフォントのlocl処理で別グリフへ置換され、見た目の字間と抽出文字がずれる問題を発見しました。fontkitの実際のグリフ列とpdf-libの実装を確認し、locl・分数系置換・カーニング等を計測と埋め込みで統一して無効にしました。SVG側の文字描画にも同じ設定を適用しています。PDFを画像へ変更する回避策は使っていません。

出力は引き続きRGBの校正用PDFです。CMYK・ICC・PDF/X・塗り足し・面付けは今回も未実装です。

## 検証結果

自動テストは **67件成功**（既存26、デザイナー29、今回のエディタ12）。TypeScript型チェックとVite本番ビルドも成功。チャンク容量の警告は残っており、読み込み容量削減は今後の課題です。

実ブラウザで確認した操作：

1. 表を新規作成し、名前を指定して編集画面へ進む。
2. 見出し背景を#4c4340へ変更し、列1の幅比率を43から55へ変更。
3. 仮データ30件を選び、3ページへ自動分割されることを確認。登録企画は5件のまま。
4. インデックスを新規作成し、四角へ変更、挨拶の章色を#555555へ変更。
5. 用紙をクリックして「未来へつなぐ、稲友祭」を直接入力・確定。
6. 長方形をドラッグ作成し、選択して移動。
7. 右クリックで複製し、取り消しで戻す。
8. レイヤーを追加し、レイヤー1を前面へ移動して一覧の順序が変わることを確認。
9. 画像ツールのファイル選択から、提供された縦長ポスターを配置。60×約85.27mmで比率を保持。
10. 制作モードで作成済み表デザインを選び、元の企画一覧の見出し・企画データを保持したまま外観を切り替える。
11. .pamph保存・再読み込み後に、6種のテンプレートと表の色・幅設定を復元して再編集。
12. 制作モードから8ページのPDFを実際にダウンロード。全ページ148×210mmを検証し、3ページ目をPopplerでレンダリングして目視確認。「FLOS館 1階 C101」の文字抽出も確認。

1280×720、1440×900、1920×1080で実スクリーンショットを取得し、横方向のはみ出しがないこと、アートボード全体が上下に収まることを確認しました。右パネルの長い設定は領域内を縦スクロールします。選択されたツール・オブジェクト行の背景は実測rgb(58,62,69)でした。

証跡：docs/screenshots/ui-1280x720.png、ui-1440x900.png、ui-1920x1080.png。寸法と色の実測はdocs/ui-viewport-verification.json、PDFの構造と文字抽出はdocs/ui-pdf-verification.json。確認用PDFはoutput/pdf/ui-verification.pdf、保存・復元用のテストプロジェクトはoutput/ui-verification.pamphです。

## 残る制約と次の改善

- 初めて使う学生本人によるユーザーテストは未実施です。開発側の操作検証が成功したことと、説明なしで誰でも使えると実証したことは区別します。
- Windows実機・他ブラウザ・入力支援技術の網羅検証は未実施。全ショートカット・全組合せのUI自動テストではありません。
- プリセットの種類は増やしましたが、任意形状インデックス、結合セル、比例時間軸、複数の流し込み領域、入れ子グループ、任意フォント、外部ベクター貼り付けは未実装です。
- アプリのダークテーマは固定です。ライトテーマ切り替えは今回の対象外です。
- ルーラーは表示専用のmm目盛りです。ルーラーからガイドをドラッグ作成する操作はまだありません。
- タッチ端末や小さいスマートフォン向けのUIではありません。今回の指定されたPC3サイズを対象にしました。

補足：モード復帰後の見開きはDOM実測493.33px（各A5約246.66px）へ復帰することを確認しました。開発途中のHot Module ReplacementではuseEffectの依存配列を2項目から3項目へ変更した時点のReact警告がログに残りました。最終コードでは依存配列を固定し、再読み込み・モード往復・型チェック・ビルド・テストを確認しています。
