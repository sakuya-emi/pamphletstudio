# v15改善点への対応

v15の新規8項目を対象に実装しました。従来のSPEC-A/E/Iは今回変更していません。

| 指摘 | 対応 |
| --- | --- |
| 1：アンケートが無言で未反映 | URL未設定のアンケートページへ初めて取り込む行は、見出し・本文が異なっていても「更新」を初期選択します。既存URLの変更や複数候補で要確認の場合は、その行を更新または明示的に登録しないとするまで登録ボタンを無効にし、理由と対処を表示します。 |
| 2：他シートとの競合 | 有効な「アンケート」行があるときは、そのシートがアンケートページのURL・見出し・本文を管理します。「お知らせ・注意事項」「ページ用テキスト」で同じアンケートを指す行は理由付きで登録対象外とし、選択変更でも二重更新しません。古いExcelにアンケート行がない場合は従来の取り込みを維持。 |
| 3：URLの併記 | QR下部の誌面・PDFに正規化済みURLを印字します。通常のURLは全体を折り返して表示。3行に収まらない極端に長いURLは省略を明記してQRの利用を案内するため、印刷でURLを伝える場合は短い共有URLを使用してください。QR本体には全URLを保持します。 |
| 4：ステップ2の編集 | 「共通情報・文章」にアンケートURL（QRコード）の行を追加。URLを確認・変更でき、変更時もhttp/httpsと文字数を検証します。空欄にすると未設定警告へ戻ります。 |
| 5：式典誌面の余白 | 同じ単独ポスターブロックの中で、連続するポスター不要の企画をテキスト表へ詰めて配置します。開会式・閉会式は一つの誌面にまとめられ、開始・終了時刻も表示。必要なポスターは元の順序で独立配置し、手動順序・別のブロックは強制結合しません。総ページ数は4の倍数調整によって同じになる場合があります。 |
| 6：箇条書きアクセント | 適用できる本文ページがない場合は、カードを理由付きで無効化します。適用対象がある冊子では従来どおり選べます。本文ページのない冊子で押すと失敗する状態を解消しました。 |
| 7：未配置広告 | 未配置の理由として、同じ規格の空き枠があるか・ないかを警告に明記。既存の広告タブの枠選択・規格別広告ページ追加への案内を表示します。広告枠を黙って追加する動作には変更していません。 |
| 8：PDF待機中の不安 | フォント読込・組版とフォント埋込・ページ処理・ファイル仕上げの段階を表示。ページ処理中は割合を表示し、初回は30秒以上かかる場合がある旨を明記。生成アルゴリズムの高速化を実施したものではありません。 |

## 検証

- アンケート初期選択・再取り込み・更新確認、他シート競合と旧Excelの互換、URL印字と編集、式典の詰め配置、箇条書きの選択不可理由、未配置広告の理由を回帰テストに追加。
- PDFの実生成テストでは進捗が単調に増え、保存前に95%、保存完了後に100%が返ることも確認。
- Chromiumで見出し・本文入りExcelのアンケートが初期選択で反映されること、競合するお知らせが上書きしないこと、共通情報タブのURL欄の変更、URL印字、進捗案内とPDFの実ダウンロードを確認。箇条書きアクセントの無効化も確認。未処理JavaScriptエラー0件。
- QRコードとURL印字の編集領域は分け、併記した文字列の編集範囲が本文全体を覆わないようにしています。
