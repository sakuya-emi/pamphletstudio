# 参考資料の確認と今回の採用内容

開発指示書を最優先とし、添付資料中の制作作業の指示は参考仕様として扱いました。マニュアルにあるIllustratorでの操作やA3指定を、今回のアプリの実行手順としては採用していません。

## 2025年「パンフ第2稿-1.pdf」

実ファイルは42ページ。マニュアルの「2025年46ページ」という記述とは一致しません。これは第2稿のファイルであり、完成版の総数を断定しません。

- PDF2ページ：短い縦線と日本語見出し／小さい英語見出し、外側の縦インデックス、端のノンブル。
- PDF3ページ：目次。章の開始ページを参照する自動目次に置き換えました。
- PDF8ページ：時刻が横に並び、企画名を縦配置するタイムライン。専用テンプレートは次段階です。
- PDF11ページ：本館／FLOS館／屋外／キッチンカー等でまとめた企画一覧。今回の表は建物・階・教室で並べ、団体名も追加した可変行高の表として構築しました。
- PDF15ページ：飲食ポスターを2列で配置し、最終行の空きがある構成。
- PDF17ページ：学生ポスター4枚と下端の横長広告。今回のT09の直接参考です。原稿の全面画像としては再利用せず、均等な2×2枠・広告実寸・余白に分解しました。
- PDF30〜31ページの抽出テキスト：協賛企業一覧。マニュアルと併せ、法人格を除いた英語→50音順のデータ処理を用意しました。専用T15は未実装です。
- PDF32ページ：協賛広告。広告規格を分け、最大高さから1/2・1/4を求めるテンプレートへ再構成しました。

## 2026年「デジタルパンフ.pdf」

実ファイルは52ページ。多くのページは文字抽出が困難なため、ページ画像を補助確認しました。PDF12ページの企画一覧はFLOS館・体育館・屋外・模擬店の場所を明示し、2025年版とは異なる装飾と配色です。今回は2025年版の共通デザインを優先し、登録データ側に建物・階・教室・開催場所を分ける参考にしました。全52ページの内容をデータとして転記したものではありません。

- PDF4ページ：協賛企業の並び、広告サイズは最大の1/2・1/4、スタッフの役職・学年・50音順。
- PDF5ページ：誤字、アウトライン、CMYK、参照切れ、塗り足し、文字サイズ、ノンブル、広告寸法、表紙ロゴの最終確認。

## A5への適用

最終仕上がりを148×210mmとし、A3面付けは独立工程にしました。本文余白は初期9mm＋インデックスとの離隔です。当初の広告実装は126×180mm、1/2を90mm、1/4を45mmとしていました。2026年11月6日の追加指示により、現在は幅125mm、高さ180／85／45mmの独立した広告規格に更新しました。制作マニュアルの比例規則より最新指示を優先しています。学生企画の素材枠は、追加された1052×1495pxのポスター比率を基準に縦長へ統一しました。T09の下広告は45mmを確保し、残りを2×2ポスター枠へ配分します。したがって「上3/4／下1/4」を面積比の固定値としては扱いません。

標準PDFはRGB校正用です。マニュアルのCMYKとアウトライン要件を満たした入稿用PDFだと表示しないよう、UIとREADMEで未実装を明示しています。
