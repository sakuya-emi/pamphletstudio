# Excelから誌面確認まで

1. 新しい冊子を作り、デザインを選ぶ。
2. 「Excelファイルを選ぶ」から .xlsx を開く。読み込まれた行を確認し、「○件を登録」を押す。
3. 企画名・企業名を見て、画像を1件ずつ登録する。画像が届いていない項目は「あとで登録する」で進める。
4. 登録済みと未登録の件数を確認し、誌面を開く。登録済みの情報は掲載情報または誌面から修正できる。

新しい掲載情報はExcelファイルで登録する。CSV・TSV読込と表の一括貼り付けは制作画面から外した。既存行の修正、CSV出力、画像差し替え、保存済み冊子の読込は引き続き使える。進行中の冊子を再開すると、Excelまたは画像の登録に戻る。

ブラウザで新規冊子の作成、Excelから学生企画と広告の登録、両方への画像登録、誌面への移動、掲載情報の企画名修正と画面移動後の保持を確認した。
