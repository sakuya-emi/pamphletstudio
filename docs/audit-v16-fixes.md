# 実機確認からの追加修正

前回の「式典を詰めて配置」は同じページにまとめただけで、ページ自体の余白を解消していませんでした。PDF進捗も、コールバックの追加を実機で見える表示まで確認したものとして報告してしまいました。今回の変更では両方の実画面を確認しています。

## 修正

- **式典の余白**：ポスター不要の企画が既存の標準タイムテーブルや同種の企画一覧に掲載される場合、重複するポスター紹介ページを作らず、そちらへ集約します。開会式・閉会式はタイムテーブルで開始・終了時刻を併記。タイムテーブルも一覧もない冊子では、内容を失わないようテキスト表のページを残します。独自デザインのページや別ブロックは勝手に結合しません。
- **実際に見えるPDF進捗**：専用の進捗パネルに描画済みページ数／総数、経過秒、処理段階、プログレスバーを表示します。フォント読込中は0ページで待機する理由を示し、ページ描画開始後はWorkerの実数で更新します。生成速度を改善したという変更ではありません。
- **アンケート以外の要確認行**：全ての要確認行が未確定の間は登録を止め、理由を表示します。更新・新規追加・登録しないの明示選択が必要です。要確認をすべて登録しない場合も、件数付きのボタンで利用者自身が選択します。
- **URLの対応位置**：QRと同じ横位置・幅（x=88mm、幅47mm）でQRの直下にURLを表示。極端に長いURLは省略を明記する従来の制限があるため、手入力のフォールバックが必要なら短い共有URLを使用します。
- **広告の配置**：候補がない場合は「同じ規格の空き枠なし」と表示。追加ボタンもページ追加・白紙再計算を明記し、実行後は出力ページ数と自動白紙数の前後を通知します。規格の異なる枠を空き枠として提示することはしません。
- **箇条書きの選択時期**：適用先がない場合は、標準のまま進められること、Excelで本文ページを追加後にステップ3のページタブから選べることを案内します。

広告名の訂正は「架空・空企画」として扱います。「株式会社さくら商事」を実データとして追加する変更はありません。SPEC-A/E/Iは引き続き対象外です。

## 検証

- ローカル全243件・33ファイル成功。その後、タイムテーブルがない場合の内容保持テストを1件追加し、そのファイルの4件も成功。既存回帰テストは、単に空白ページを残すことを成功条件にせず、タイムテーブルに企画名が残り、重複する紹介ページが消える条件へ更新。
- `/pamphlet-studio/` 用の型チェック・本番ビルド成功。
- Chromiumで実Excelを選択し、禁煙などの要確認行があると登録ボタンが無効になり、明示的に登録しないことを選択後に進めることを確認。
- フォント取得を一時的に保留し、実画面で「描画済み0／28ページ・経過1秒」とプログレスバーを確認して画像を保存。保留を解除して実際にPDFを生成し、画面のページ数が1、2、4、5、6、10、12、15、19、22、27、28と増えることをDOMで観測。架空のタイマーでページ数を増やしているものではありません。
- 同じ検証用冊子で式典の専用紹介ページが0件、タイムテーブルに掲載が残っていることを確認。広告ページ追加時のページ数・白紙数の増減通知も実画面で確認。PDFを実ファイルとしてダウンロード。未処理ブラウザエラー0件。
