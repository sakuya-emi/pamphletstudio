# 入力の簡素化・企画分類の変更記録

2026年11月7日

## 変更範囲

今回の依頼を受けた時点の作業フォルダを基準に差分を記録しました。ダークテーマ、作図ツール、表A/B/C、インデックスの形状、ページ番号、A5寸法、フォント、PDF出力エンジン、素材取り込み処理、テンプレートファイルの保存処理は刷新していません。既存の企画一覧とポスターの連続配置を維持しています。

### 登録画面

- 学生企画、模擬店、ステージ企画、学生ステージ企画、キッチンカーを別タブにしました。
- スタッフの入力列は氏名だけです。旧データの学年・役職・読み仮名は残します。
- 広告の入力列は企業名・広告サイズ・広告データだけです。同じ企業名は内部で再利用し、複数の広告を独立して保持します。企業名の前後空白・全半角・英字大小の差を吸収します。広告原稿を勝手に統合する処理ではありません。
- ID・企業ID・広告IDは入力表と表示列の選択から外しました。画像セル、広告、企画の関連付けは内部で処理します。
- 新規登録する企画・スタッフ・広告・企業・メニューは、文字列の自動番号を使います。採番の進行値を保存し、削除後も既存番号を変更しません。旧UUID・その他の文字列ID、素材やテンプレートの既存IDはそのまま保持します。
- ステージ2種は企画名・開始時刻・終了時刻・ポスターの4列です。時刻の不足・形式・前後関係は入力内容を保持して警告します。
- キッチンカーは会社名・複数メニュー・画像の3列です。「＋ メニューを追加」、削除、上下移動に対応します。画像登録で会社名やメニューを初期化しません。
- 制作モードの既存右パネルも、ステージには時刻、キッチンカーには会社名とメニューだけを表示するよう必要範囲で調整しました。

### 自動反映

- 一覧表は学生企画・模擬店・キッチンカーから取得します。ステージ2種を除外し、既存の表テンプレートを使えます。
- キッチンカーの会社名を一覧の名称に使い、存在しない教室や「0階」を補完しません。画像は専用紹介ページに置き、通常の学生ポスター紹介へ重複配置しません。
- ステージを登録すると専用セクションを追加し、2種を開始時刻順に自動配置します。種類はラベルと配色で区別します。ポスターがあれば専用紹介ページを生成し、通常と同じ4枚＋125×45mm広告枠を使います。
- 横時間軸＋縦配置の名称、縦時間軸の2種類を追加しました。デザイナーモードの既存ライブラリから複製・保存・選択できます。方向、文字の向き、文字サイズ、ラベル間隔、学生ステージ色、既存の枠・配色・掲載件数を変更できます。長い名称が時間枠に収まらない場合は、全文を補足ページへ組版します。
- キッチンカー紹介は2件／ページを基本にし、メニューが多ければ同じ会社の続きとして追加配置します。
- 種別変更でも既存の入力項目・画像・メニューを削除しません。新たにステージ／キッチンカーへ変更した場合も必要なセクションを作ります。

## 保存互換性

.pamphのZIP構造とスキーマ5を維持し、任意項目 nextRecordId、kitchenMenus、企画種別 studentStage を追加しました。メニューは独立IDと企画IDで関連付けます。旧形式1〜4の既存移行経路を維持し、旧スタッフの項目や既存素材参照を保持します。日本語の既知の企画種別表記と student-stage は現在の種別へ対応付けます。

今のアプリが旧ファイルを読めることを確認しています。新しい専用ページ種別を持つファイルを以前のアプリで開けることまでは保証しません。今回の差分は「本依頼を受けた時点のこの作業フォルダ」に適用するものであり、以前の任意の版へ単独適用できるパッチではありません。

## 制約・未完成項目

- 新しいステージのテンプレートは方向・文字・配色・枠・件数中心です。時刻ラベルの任意位置指定や独立した複数領域への流し込みなど、専用の高度な配置UIは未実装です。極端な同時開催や小さい任意サイズの組合せは追加検証が必要です。
- キッチンカーの紹介は今回必要なデータ連動を持つ2件配置です。任意の新しいキッチンカー専用部品エディタは追加していません。画像の角丸マスクなども変更していません。
- 旧データでキッチンカーの会社名と企画名がどの項目に入っているか不明な場合、推測して入れ替えません。既存の名称を会社名欄に表示し、他の旧項目は保持します。
- PDFは既存通りRGB校正用です。CMYK・ICC・PDF/Xは今回の変更範囲外です。既存の大きいバンドルの警告は残っています。
- 全ブラウザ・Windows実機・すべての操作組合せの検証は未完了です。

## 差分ZIPの適用

既存フォルダをバックアップし、ZIPの中身をプロジェクトのルートへ相対パスを保って上書きしてください。新規ファイルも同じ相対パスへ配置してください。削除が必要なファイルはありません。node_modules・ビルド成果物・一時ファイル・キャッシュ・参考PDF・画像・変更していないソースは同梱しません。依存ライブラリの追加・更新はありません。
