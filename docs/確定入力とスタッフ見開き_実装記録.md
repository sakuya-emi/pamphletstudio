# 確定入力とスタッフ見開き

- 裏表紙の円内ラベルは、二行を一組として上下・左右の中央に配置する。
- 新規冊子のアンケートURLは空欄にし、未入力・無効時は「QRダミー」「クリックしてURLを入力」を表示する。ダミーはPDFに出力しない。登録済みURLは変更しない。
- 企画一覧ではキッチンカーを「屋外」に分類し、開催場所を「マップに記載」と表示する。登録済みの建物・場所の値は上書きしない。標準表とデザイナーの表で共通の扱いにする。
- 新規冊子は裏表紙直前にスタッフ紹介を見開きで用意する。人数が増えたら見開き単位でページを増やす。中綴じ用の調整白紙はスタッフ紹介より前に配置する。既存冊子のページ構成は自動で差し替えない。
- 制作モードの直接編集、ページ見出し・本文・アンケートURL、企画パネルの文字入力などは、Enterまたは入力欄から離れた時に確定して組版する。複数行欄はShift+Enterで改行。日本語IMEの変換確定に使うEnterでは組版を実行しない。選択欄や画像の取り込みは従来どおり反映する。

スマートフォン幅のブラウザで、URL入力中はダミーのまま、EnterでQRに切り替わることを確認。左右綴じのスタッフ見開き、キッチンカーの表示、ダミーの非印刷を自動テストで確認。公開サーバーへは未転送。
