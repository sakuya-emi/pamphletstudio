# 挨拶・案内ページと冊子の配色

更新日：2026-11-07

## 操作

- 実行委員長・副委員長挨拶のページ設定「副実行委員長の掲載方法」で「二人まとめて」または「二人を別々に」を選択する。まとめる場合は二人の氏名と共有の写真・本文を表示し、別々の場合は二人目の写真と本文を個別に表示する。切り替えても登録値は削除しない。挨拶には一般のお知らせ用「項目を追加」ガイドを重ねない。
- 禁煙・禁酒ページではそれぞれ「イラスト付きマーク」「文字付きのシンプルなマーク」を選べる。「画像を追加」で取り込んだ素材は同じ冊子内の選択肢に蓄積し、素材を切り替えても残す。.pamphに保存し、次年度用複製へも引き継ぐ。別の新規冊子へ自動同期はしない。
- ゴミの分別は、区分を結合セルにして品目を行に並べる2列の表。ページ設定で各区分の品目を1行ずつ入力できる。
- デザイナーモードの「冊子の配色」からパレットを登録・命名し、色選択または16進色コードで設定する。制作モードの「デザイン」から登録済みパレットを選ぶ。「標準の配色」で元の配色へ戻せる。
- 既定のマップ見出しを「マップ」にし、他の本文ページと同じ位置・縦線・書体で表示する。
- ポスター4枚＋広告は画像の位置を維持し、背景は冊子設定、ノンブルは既存の小さい標準表示に戻した。
- 新規の協賛広告ページとデザイナーの広告プリセットは1/2広告を標準とする。1/4広告4件の縦積みは新規選択肢から外した。既存の縦積みページは保存された指定を維持する。ポスター下の1/4枠・広告素材の1/4サイズ登録は維持する。

## 配色の仕組みと互換性

パレットは元の16進色をキーに、表示する色を記録する。同じ元の色が使われる背景、文字、線、図形、表、章タブへ一括反映する。既存テンプレートの設定値を破壊せず、プレビューとベクターPDFが同じ描画色を使う。写真・広告などの素材そのものとQRコードは色変換しない。パレットと選択状態は.pamphに保存する。スキーマバージョンは維持する。

## 検証

- ブラウザで副実行委員長の表示切替、パレット登録・色コード入力、分別表と複数ページの配色反映を確認。
- 自動テストで挨拶の保持、画像ライブラリの保存・引き継ぎ、配色の復元とQRの保護、マップ見出し、新しい広告プリセット、ポスターの配置・背景・ページ番号を検証。
- 公開サーバーには今回の変更を転送していない。
