# デザイナーモード：実装状況・操作・引き継ぎ

更新日：2026-11-06。これは圧縮していない現行の開発記録です。以前の「開発状況と引き継ぎ.md」は基礎Web版の履歴として残しています。本書とOSS調査書を今回の追加開発の基準にしてください。

## 今回の判断

既存の制作モード、固定テンプレート、プロジェクト保存、PDF出力を維持して、TypeScriptによる編集可能なテンプレートモデルを追加しました。VectorCraftとDesignCraftのエンジンは組み込んでいません。両プロジェクトのコードを流用した実装とも表示しません。Rust/WASMの実ビルド・ブラウザ実行は未検証です。調査根拠、ライセンス、再利用候補、統合の条件は「デザイナーモード_OSS調査と統合判断.md」に記録しました。

## 起動と基本操作

READMEに従い npm install / npm run dev で起動します。制作画面上部の「デザイナーモード」から入ります。一般担当者は従来の制作画面で情報登録を続けられます。

1. ライブラリから自由配置・表・ポスター・時間割を作成するか、既存デザインを選びます。
2. 左のツールで図形・文字・画像枠を置きます。選択ツールでドラッグ移動、右下ハンドルで拡大縮小、上のハンドルで回転できます。位置・寸法・角度は右側でmm単位指定できます。
3. Shiftを押して複数選択するか、空白から囲んで選択します。整列・均等配置・グループ化・複製を使えます。画像は枠の中に縦横比を維持して全体表示します。
4. 文字を選んで右の本文欄、文字サイズ、太字、色を編集します。データ項目を設定すると固定文字の代わりに参照値を表示します。
5. ペンはクリックで点を置き、Enterまたはダブルクリックで確定します。アンカーツールで点を移動し、制御点を追加してベジェ曲線を編集できます。パスを閉じる操作もあります。
6. 自動組版パーツを追加すると企画データを反映します。表・ポスター・時間割のいずれか一つを、一つのデザインの繰り返し領域として使います。
7. 「選択ページに適用」または「新しいページとして使用」で制作モードへ戻ります。制作画面右の「デザインバリエーション」からサムネイルで切り替えられます。
8. 「PDFで確認」はそのテンプレートだけを標準PDFへ出力します。制作画面のPDF出力ではパンフレット全体を出力します。
9. 変更はプロジェクトに随時反映し、ブラウザに自動保存します。「プロジェクト保存」で素材込みの.pamphを外部保存してください。
10. 「書き出し」は素材と必要な共通マスターを含む.pamptpl（読み取り可能なJSON）です。「読み込み」で別のプロジェクトにも追加できます。読み込み時にIDを振り直し、素材を再検査します。

デザイナー画面はPCでの利用を前提にしています。狭い画面ではパネル内をスクロールしてください。ツールのアイコンには名前とショートカットの説明があります。

## 編集機能の範囲

実装した操作は、単一・複数選択、囲み選択、移動、サイズ変更、回転、長方形、楕円、直線、ペンパス、アンカーと曲線制御点、文字、画像枠、塗りと線、透明度、グループ、レイヤーの追加・名前・表示・ロック・順序、オブジェクト前面背面、整列・均等配置、mm数値指定、ガイド、グリッド、スナップ、パン、ズーム、複製、内部コピー・ペースト、Undo/Redoです。

回転後の外接範囲、パスの点と制御点がA5を超える変更は拒否します。制御点まで制限するため、曲線自体が紙面内でも操作を拒否する場合があります。これは保守的な制約です。線幅の外側やフォントの細かな字形外形を含む完全な印刷プリフライトではありません。

グループは共通IDによる一段の集合です。Illustratorの入れ子のグループ、パス演算、任意クリッピング、マスク、グラデーション、段落スタイル、文字のアウトライン化、外部アプリとのSVGクリップボード互換は未実装です。キーボードのコピー・ペーストはこの編集画面内部で機能します。履歴はデザイナー画面内で最大80段階、画面を再度開いたときは新しい編集セッションです。保存ファイルには編集結果を保持し、履歴自体は保持しません。

## 自動組版と制約

### 表

列ごとの見出し、対応する企画フィールド、幅の比率、見出し高さ、最小行高、セル余白、文字サイズ、色、交互背景、罫線、建物別見出しを編集します。建物・階・教室の順で並べ、長文を折り返し、枠に収まらなければ同じ表を次ページに作ります。見出しを繰り返し、一つの行が枠を超える長さの場合も続きを別ページへ送ります。結合セルや任意の二次元セル編集は未実装です。

### インデックス

位置、寸法、角丸、間隔、文字サイズ、縦・横の文字配置、非選択時の透明度、左右反転を編集します。章名・色は制作モードの章設定を参照し、現在の章を強調します。物理ページ順・綴じ方向から外側を判定します。任意パス形状のタブ、選択状態ごとに完全に独立した文字・装飾セットは未実装です。

### 時間割

企画に開始・終了時刻を登録し、数値化した開始時刻順に並べます。横・縦方向、時間表示、企画名、場所、バーの色と線、余白、最大掲載件数を設定できます。長い名称もページへ分割します。現在は企画ごとのバーを並べる形式で、時刻の経過量に比例した厳密な共通スケール、同時刻の会場レーン、任意の分割規則は未実装です。

### ポスターと広告

行・列・間隔と領域を指定し、企画件数に応じてページを自動生成します。枠は添付の縦長原稿比率1052/1495を維持し、画像を変形・自動トリミングしません。ポスター名称は最大2行の表示です。全文は企画データと一覧表に残ります。

広告枠は画像に「協賛広告」の役割と full / half / quarter 規格を設定します。自動割当は同じ広告を使い回しません。広告未設定の枠はプレースホルダーと警告になります。広告種類のテンプレートは規格ごとの枠数と登録広告数から改ページします。設定寸法の初期値は125×180、125×85、125×45mmです。halfは独立した85mmです。

### 共通マスター

流し込み領域を持たないテンプレートを別テンプレートの共通マスターに指定できます。マスターの図形は子テンプレートの下に描き、マスター変更は参照先にも反映します。共通背景は子テンプレートの背景色を使います。マスターは一段のみで、循環・マスター同士の連鎖は禁止です。削除時は参照を解除します。マスター由来のオブジェクトはマスターを開いて編集します。

## データバインディング

固定文字のほか、企画名・団体名・場所、企画ポスター、協賛広告、ページ番号、章名、学園祭名、開催日を参照できます。自由配置の企画参照は自動生成ページの番号に対応する企画を参照します。表やポスターの各セルは専用の繰り返し処理で企画を順に参照します。汎用の式言語、条件分岐、任意のリレーショナル結合はありません。

一つのテンプレートに複数の表・ポスター・時間割を配置して相互に連鎖させる機能はありません。自由配置と一つの繰り返し領域を組み合わせ、固定部分を保ったままデータ量に追従させる実装です。自動生成後の個別ページだけを別々に自由編集する形式ではありません。

## 実装構造と互換性

- packages/designer/model.ts：テンプレート・レイヤー・オブジェクト・バインディングと検証。
- packages/designer/geometry.ts：mmのパス・外接領域・回転・制約。
- packages/designer/render.ts：テンプレートを共通Node配列へコンパイル、表・ポスター・時間割の改ページ。
- packages/layout-engine/types.ts：識別子、パス、回転、変換原点、不透明度、レイヤーとグループのメタデータ。
- packages/layout-engine/index.ts：従来の固定テンプレートとカスタムテンプレートの選択、広告割当、順序確定、ページ番号。
- apps/web/src/Designer.tsx：編集UI、操作履歴、パネル、JSON入出力。Preview.tsxのNodeViewを共用。
- packages/pdf-export/index.ts：共通NodeからPDFへ描画。パス・回転・透明度を追加。PDF素材は原本ページの埋め込みを維持。
- packages/project-storage/index.ts：schemaVersion 1/2を3へ移行。テンプレート、マスター参照、素材を検証。

ProjectのschemaVersionは3です。形式2の固定ページは変更せず、templates=[]を追加します。形式1は先に独立広告寸法へ移行します。Block.templateIdが無ければ従来のモジュールを使います。templatesはproject.json内に保存し、画像原本は.pamphのassets配下に保存します。マスター参照や未知バージョンを検証します。次年度複製ではテンプレートとそれが使う固定素材を保持します。

既存の固定レイアウトは全面変換していません。「現在のページを図形として取込」は見た目を静的要素として取り込む機能で、元の表などを自動的にデータ連動パーツへ認識し直すものではありません。連動を継続するには専用パーツを配置してください。標準目次は引き続き既存のエンジンで自動計算します。カスタムの目次組版エディタは未実装です。

## PDFと品質確認

SVGプレビューとPDFは同じmmのNodeリストを使います。図形、文字、表、インデックス、ベジェパスをPDFの描画命令へ変換します。画面のキャプチャは使いません。フォントはNotoの実フォントを埋め込み、PDF素材はForm XObjectとして埋め込みます。ガイド・選択枠は出力しません。

標準PDFはRGBの校正用です。CMYK・ICC・PDF/X・塗り足し・面付けは未実装です。フォント全体埋め込みにより約23MBからとなり、容量削減は残課題です。画面とPDFの文字アンチエイリアスはレンダラーごとに差があります。

自動テストは既存26件＋追加29件の55件が成功しました。型チェックとVite本番ビルドも成功しました。追加テストには形式移行、素材を含むZIP復元、マスター、循環拒否、企画0/5/30件、長文の表改ページ、ポスター1/4/5/11件、広告重複防止、時刻順、長文時間割、非表示レイヤー、回転とパス、ベクターPDFを含みます。詳細はtests/designer.test.tsにあります。

実ブラウザでは長方形・楕円・文字作成、数値と回転、複製、Undo/Redo、複数選択とグループ解除、削除、テンプレート書出しと再読込、制作ページへの適用を確認しました。保存済みテンプレートは読み込み後も5個のオブジェクトを保持し、制作モードに独立ページとして追加されました。さらに.pamphの外部保存・再読み込み後も8ページと3種のテンプレートを復元し、自由配置の5要素を再編集できることを確認しました。コンソールのerror記録はありませんでした。全ての操作の組合せを網羅したブラウザ自動テストではありません。

output/pdf/designer-verification.pdfはテストから生成する確認用PDFです。Popplerで画像化し、回転長方形・楕円・ベジェ・日本語・回転文字を目視確認しました。docs/screenshots/designer-mode.pngは実際の編集画面です。

## 次の開発順序

1. タイムテーブルを比例時間軸と会場レーンに拡張し、実データで情報密度を検証する。
2. インデックスの任意形状・状態別スタイル、表の結合セルと書式、複数領域の流し込みを必要性に応じて追加する。
3. 自由文字とポスター名のはみ出し警告をテンプレート編集時にも詳しく表示する。
4. 編集操作の組合せを増やしたUI回帰テスト、Windows/macOS実機・異なるブラウザでの検証を行う。
5. Rustツールチェーンを整え、別の最小検証アプリでVectorCraftの形状処理をWASM化して速度と境界型を測定する。合格するまで現行エンジンは置き換えない。
6. 印刷会社のICCとPDF/X仕様を得た後、校正PDFとは独立した印刷変換・検証工程を作る。

現時点の成果は編集・保存・適用・再利用・ベクター出力を持つ最初のデザイナーモードです。Illustrator相当の全機能、両OSSの統合、全ての要求項目の完成を意味しません。
