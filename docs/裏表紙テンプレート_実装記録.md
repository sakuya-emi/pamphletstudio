# 裏表紙テンプレート

更新日：2026-11-07

「新規作成」では、上段にメイン画像、下段に大学周辺マップと公式サイトQRを置く裏表紙を用意する。初期値は「マップ左・QR右」。制作モードで裏表紙を選び、ページ設定「裏表紙のレイアウト」から「QR左・マップ右」に変更できる。後者は参考の2枚目に合わせて上段画像枠を高くする。参考スクリーンショットのイラストは流用せず、上段にはユーザーの画像を縦横比を保って配置する。未登録の枠は編集時だけ表示する。

添付の大学付近マップを初期画像としてプロジェクト内へ取り込む。学内マップとは別の素材。周辺マップを差し替えた場合も2構図の切り替えで保持する。初期QRは https://www.nagoya-bunri.ac.jp/ 。ベクターとして生成し、冊子パレットを適用してもQRの白黒は維持する。QRのクリックまたはページ設定でURLを変更できる。

既存プロジェクトは従来の裏表紙を維持する。裏表紙のレイアウトを選ぶと新構図へ切り替え、周辺マップが未登録なら初期画像を取り込む。構図・素材・URLは.pamphに保存する。年度更新では周辺マップを引き継ぎ、上段のメイン画像は従来どおり再登録する。

ブラウザで2構図への切り替えと、添付マップの表示、QRのURLを確認。自動テスト160件成功。本番ビルド成功。公開サーバーへの転送は今回行っていない。
