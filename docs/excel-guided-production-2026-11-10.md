# Excel一括登録・制作導線の改修（2026-11-10）

新規作成 → デザイン → 基本情報 → 掲載情報 → 仕上がり確認 → 最終確認・PDF出力。既存のデザイナーモード、保存形式、A5ベクターPDFを維持。表紙のないカードにはプロジェクト名を表示し、テンプレート追加は見本から生成したサムネイルを表示する。完成見本は架空データの独立した編集用コピー。

掲載情報の「Excelから一括登録」で .xlsx を選ぶか、登録先を選んでセル範囲を貼り付ける。既存項目との同名候補は自動統合しない。更新先と削除対象は確認画面で表示する。空欄は既存値を維持し、画像・割当付き項目は置き換え時に保護する。一括登録は取り消し可能。

## シート別対応

- 基本情報：大学名・学園祭名・開催回数・日付・時間・テーマ。
- 学生企画、模擬店：企画・団体・建物・階数・教室・詳細場所。
- ステージ企画、学生ステージ企画：別種別で保持し、開始時刻順のタイムテーブルへ反映。
- キッチンカー：会社名と最大5列のメニュー。
- 協賛企業：企業名・読み仮名・並び替えキー。
- 広告：企業名とサイズ。画像・PDFは後から。
- スタッフ：分類を引き継ぎ、氏名表記を維持。ファイル取込時は記入例混入防止のためスタッフ行を初期選択しない。
- 章・インデックス：選択した章を入力順に配置。既存章の設定を保持できる。
- 挨拶：肩書に対応する既存の氏名・本文欄。写真は維持。
- お知らせ・注意事項：既存ページに反映するか案内ページを追加。
- 外部・特別企画：独立した案内ページとして掲載。
- ページ用テキスト：タイトルを照合し、候補から掲載先を選択。
- はじめに：対象外。

## 監査・検証

A、B、C、E、F、Gはコードで原因を確認。初期案内・見本、白紙の代替表示、テンプレート一覧、番号の説明、フォーム保存、最終出力への集約、同名対策と削除確認を実装。Dの固定日付は現行ソースで確認できず公開版の再現条件は不明。標準表紙と冒頭のお知らせに入力した開催日だけを描画する。画像に焼き込まれた日付は素材の差し替えが必要。

改修前の本体169件は成功。展開済み納品フォルダのテストコピー2ファイルが誤収集されたため、出力フォルダをテスト対象外にした。改修後は自動テスト176件、型チェック、公開パス指定の本番ビルドが成功。ブラウザでTab移動・画面切り替え・自動保存からの復元、添付ファイルの読込プレビュー、別のデータの貼り付け登録、完成見本、最終画面からのA5校正用PDF出力を確認した。

未検証：スマートフォン実機、保存失敗の強制再現、実プロジェクトの削除、公開環境への反映。次回はこの4点を優先して確認する。校正用PDFのRGB仕様は従来通り。削除したソースファイルや保存形式の変更はない。
