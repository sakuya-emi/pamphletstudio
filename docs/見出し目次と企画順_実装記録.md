# 見出し目次と企画ページ順

目次はインデックスの章名ではなく、最終のページ順にある見出しから作る。同じ見出しが連続する場合、目次は開始ページのみ、誌面の見出しも最初のみ表示する。離れた位置で同じ見出しが再登場する場合は別の目次項目になる。目次は18項目ずつ改ページし、ページ番号は目次の長さと見開き調整が決まってから反映する。表紙、裏表紙、目次、調整白紙は目次項目から除外する。目次の文字から編集する対象はページの見出しであり、章名は従来どおりサイドタブ側で編集する。

新規プロジェクトでは冒頭11ページを維持し、登録前のPDF物理順で12ページ目から次のように並ぶ。

12. キッチンカー
13. 学生企画一覧
14. 学生企画ポスター
15. 学生ステージ企画一覧
16. 学生ステージ企画ポスター（4枚＋1/4広告）
17. 自治会ステージ企画（広告枠なし、各ページにポスター1枚）

企画が増えると該当セクション内で改ページする。登録後のページ番号は自動更新する。学生ステージの一覧は開始時刻順。自治会ステージは作業ページの「ステージ企画」を掲載し、「学生ステージ企画」と分ける。専用セクションがある新規プロジェクトでは、タイムテーブルの直後にステージポスターを重複掲載しない。既存プロジェクトのブロック構成は差し替えず、目次の生成規則を更新する。標準ポスターページは従来の画像配置を維持し、目次には論理的なセクション名を載せる。

ブラウザで新規作成時の12〜17ページと目次を確認。164件のテストと本番ビルド成功。公開サーバーには未反映。
