# GitHubへの移行

ZIPを展開し、`Pamphlet-Studio` フォルダの中身をリポジトリのルートに置きます。Node.js 22以上を使います。

```sh
npm ci
npm run dev
npm test
npm run build
```

`npm run dev` でローカル版を起動します。`npm run build` は `dist/` に公開用ファイルを出力します。サイトをリポジトリ名のサブパスで公開する場合は、`npm run build -- --base=/リポジトリ名/` を使います。フォントの圧縮版は起動・ビルド時に生成されます。

このZIPには現行ソース、同梱フォントと初期画像、テスト、技術文書を収録しています。過去の実装記録には、同梱していないスクリーンショットや出力ファイルへの参照があります。作成済み冊子と共通テンプレートの下書きは、元のサイトから書き出すと新しい公開先へ持ち込めます。
