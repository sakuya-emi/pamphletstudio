# ExcelからアンケートQRコードを設定する

全16シートの新テンプレート：`public/templates/Pamphlet-Studio-Excel-template-v3.xlsx`。

1. 「アンケート」シートの **A2（アンケートURL）** に、回答用フォームのURLを貼り付けます。`https://` または `http://` から始まるURLを使用してください。QR画像の作成・登録は不要です。
2. 見出しと本文を変える場合はB2、C2にも記入します。空欄なら現在の文章を保持します。
3. Excelをアプリへドロップします。既存URLと異なる場合は、取り込みプレビューで変更前後を確認して「更新」を選択します。
4. 誌面・PDFにURLから生成したQRコードが反映されます。

アンケート行を全て空欄にするか、古いExcelにアンケートシートがない場合は、保存済みのURLは変更しません。新規プロジェクトでURLを入れない場合、従来どおりURL未設定の警告が残ります。新しいURLは自動判定で登録候補となり、同じURLの再取り込みは変更不要になります。

基本情報6項目・ポスター要否列・既存の全シートは維持しています。元のv2テンプレートの入力例も残しているため、実際の内容に置き換えるか不要な行を削除してください。v2も引き続き読み込めます。

アンケートページがないプロジェクトでは新しいページを追加します。複数の候補ページがある場合は取り込み時に掲載先を選びます。URLは共通の検証・正規化を行い、その同じURLをベクターQRコードへ変換します。画像に変換して貼り込む方式ではありません。

## 検証

- 追加3テスト：既存ページへの反映と実PDF生成・保存再読込、新規／更新／再取り込みの判定、空欄・URL別名列・不正URL・URL未対応のプロジェクトへの追加。
- 旧テストのシート総数を15種類へ更新（「はじめに」は取り込み対象外のため、Excelの全16シートとは数が異なります）。
- Chromiumで全16シートを含む実際のv3 ExcelにテストURLを記入し、ファイル選択・プレビュー・登録・警告解消・QRパス生成・実PDFダウンロードを確認。既存のアンケートページは重複しません。未処理ブラウザエラー0件。
